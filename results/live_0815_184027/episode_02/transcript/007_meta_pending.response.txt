## Critical Limitation Identified

**The battery charge target is too conservative and misses peak-shaving opportunities.**

Current logic:
- Targets 70% SOC during cheap hours (fixed at `battery_capacity_mwh * 0.70`)
- Discharge threshold only triggers at 120% of P50 or extreme prices (>P90 * 1.15)
- Battery sits idle 43.3% of the time despite `Peak Price Impact: 196.2 $/MWh` indicating massive price volatility

**The gap to theoretical optimum ($12.02M) suggests systematic under-utilization of battery for peak shaving.**

## Specific Improvement: Dynamic Battery Targets Based on Price Volatility

### Implementation

Replace the static 0.70 target with a **dynamic charging target that scales with price dispersion**:

```python
def take_action(self, ...):
    # ... existing price history logic ...
    
    # NEW: Calculate price volatility coefficient
    if len(self.price_history) >= 24:
        sorted_prices = sorted(self.price_history)
        p10 = sorted_prices[len(sorted_prices) // 10]
        p90 = sorted_prices[(9 * len(sorted_prices)) // 10]
        price_spread = p90 - p10
        
        # Normalize spread to volatility factor (0.5 to 1.5)
        base_spread = 20.0  # Expected typical spread
        volatility_factor = 0.5 + min(1.0, price_spread / base_spread) * 1.0
    else:
        volatility_factor = 0.75
    
    # Dynamic charge target: low volatility → 60%, high volatility → 85%
    target_soc_ratio = 0.60 + (volatility_factor - 0.5) * 0.5  # Range: [0.60, 0.85]
    battery_target_mwh = battery_capacity_mwh * target_soc_ratio
    battery_deficit = battery_target_mwh - battery_soc_mwh
    
    # NEW: Aggressive discharge at elevated prices (P50 threshold, not P90)
    is_elevated_price = current_price > self.price_percentile_50 * 1.1
    
    # ... existing cheap_hour charging logic, using battery_deficit ...
    
    if is_cheap_hour and battery_deficit > 1e-6:
        available_charge_power = min(battery_power_mw, battery_deficit / 1.0,
                                   (battery_capacity_mwh - battery_soc_mwh) / 1.0)
        battery_mw = available_charge_power
    elif is_elevated_price and battery_soc_mwh > battery_capacity_mwh * 0.10:  # Lower threshold
        available_discharge_power = min(battery_power_mw,
                                      (battery_soc_mwh - battery_capacity_mwh * 0.10) / 1.0)
        battery_mw = -available_discharge_power
    # ... rest of battery logic ...
```

### Key Changes

| Parameter | Old | New | Rationale |
|-----------|-----|-----|-----------|
| Charge target | Static 0.70 | Dynamic 0.60–0.85 | High volatility (P90-P10=$196) demands fuller battery |
| Discharge trigger | P50 × 1.2 OR P90 × 1.15 | P50 × 1.1 | More frequent discharge at mildly elevated prices |
| Min discharge SOC | 0.15 (firm load buffer) | 0.10 | Tighter minimum allows more discharge capacity |

## Why This Works

The current policy conflates "expensive hour" (P50 × 1.2 = ~$72) with "discharge hour." Your observed $196.2 peak suggests occasional extreme spikes that the current thresholds miss. Dynamic targets adapt to market regime without retuning; aggressive discharge at milder elevations (P50 × 1.1 = ~$66) captures more arbitrage while volatility scaling prevents over-discharge in stable periods.
