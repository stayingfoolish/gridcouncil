# Fundamental Rethinking: Multi-Horizon Stochastic Dispatch with Dual Optimization

## Current Implementation Analysis

**Strengths:**
- Momentum-based price direction detection
- Deadline-aware backlog servicing
- Volatility-adaptive thresholds
- Battery efficiency consideration

**Critical Limitations:**
1. **Greedy Myopia**: Single-horizon decisions ignore multi-day price patterns (168-hour history underutilized)
2. **False Momentum Signal**: 6-hour window too short; noise misidentified as trend
3. **Decoupled Optimization**: Flex compute and battery charged/discharged independently—missed arbitrage opportunities
4. **95% Battery Underutilization**: Current logic rarely triggers discharge (only momentum >0.05 or price >80th percentile)
5. **Synthetic Forecast Weakness**: Averaging daily patterns removes high-value price spikes
6. **No Explicit Cost Objective**: Thresholds are hardcoded; no formal optimization of compute vs. charging timing trade-offs

**Performance Stagnation Signal**: Last 5 costs show oscillation ($14.5M–$14.8M–$13.9M–$14.5M), indicating the policy is locally stuck.

---

## Novel Approach: Coupled Stochastic Dispatch with Rolling Cost Minimization

### Core Insight
**Treat the 24-hour window as a single coupled optimization problem** where:
- Compute scheduling and battery dispatch are joint variables
- We explicitly minimize: `sum(price[t] * (firm_load[t] + dispatch_flex[t] - battery_discharge[t]))`
- Subject to: deadline constraints, battery physics, and ramp limits

This differs fundamentally from current *threshold-triggered* logic.

            daily_pattern[h] = np.median(hour_prices) if len(hour_prices) > 0 else current_price
        
        # Detect anomalies: prices > 1.5x rolling median are "spikes"
        rolling_median = np.median(hist[-48:]) if len(hist) >= 48 else np.median(hist)
        spike_mask = hist > rolling_median * self.price_spike_threshold
        spike_fraction = np.mean(spike_mask[-24:]) if len(hist) >= 24 else 0.0
        
        # AR(1) on detrended residuals
        detrended = hist - daily_pattern[np.arange(len(hist)) % 24]
        if len(detrended) >= 2:
            residuals = detrended[:-1]
            next_residuals = detrended[1:]
            if np.std(residuals) > 0.1:
                ar_coeff = np.corrcoef(residuals, next_residuals)[0, 1]
                ar_coeff = np.clip(ar_coeff, -0.8, 0.8)
            else:
                ar_coeff = 0.3
        else:
            ar_coeff = 0.3
        
        forecast = []
        last_residual = detrended[-1] if len(detrended) > 0 else 0.0
        
        for i in range(self.forecast_window):
            base = daily_pattern[i % 24]
            # Project residual forward with decay
            projected_residual = last_residual * (ar_coeff ** (i + 1))
            # Add stochastic spike probability
            if spike_fraction > 0.15 and i > 2 and i < 20:
                spike_premium = rolling_median * 0.2 * spike_fraction
            else:
                spike_premium = 0.0
            
            forecast_price = base + projected_residual + spike_premium
            forecast.append(max(10.0, forecast_price))  # Floor at $10/MWh
            last_residual = projected_residual
