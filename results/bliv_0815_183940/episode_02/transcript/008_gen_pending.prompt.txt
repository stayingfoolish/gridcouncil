**Replace the linear volatility adjustment with a sigmoid-based confidence model** that distinguishes between safe and risky volatility regimes:

```python
def _calculate_volatility_adjusted_power(self, volatility: float, base_power: float) -> float:
    """
    Sigmoid-based confidence adjustment:
    - Low volatility (<8%): Deploy ~95% of power (high confidence)
    - Medium volatility (8-12%): Deploy ~85% of power (moderate confidence)
    - High volatility (>15%): Deploy ~70% of power (low confidence)
    """
    volatility_pct = volatility / 100.0
    
    # Sigmoid centered at 0.12 (12% volatility) with steepness 25
    # This creates smooth transitions instead of hard thresholds
    confidence = 1.0 / (1.0 + np.exp(-25 * (0.12 - volatility_pct)))
    
    # Map confidence [0, 1] to power multiplier [0.68, 0.96]
    adjustment = 0.68 + confidence * 0.28
    
    return base_power * adjustment
```
