# Novel Battery Management System: Hybrid Model Predictive Control with Reinforcement Learning

## Analysis of Current Implementation

### Strengths
- State machine provides structured decision-making
- Price prediction captures trend direction
- Battery constraints are respected
- Margin-based arbitrage logic is sound

### Critical Limitations
1. **Reactive, Not Predictive**: Only looks 3 steps ahead; misses multi-hour patterns
2. **Stagnation Cause**: High volatility (10.1%) creates margin threshold conflicts - conservative thresholds miss opportunities, aggressive ones create losses
3. **State Rigidity**: Once in CHARGING/DISCHARGING, locked until 15%+ margin or timeout - ignores sudden price reversals
4. **No Learning**: Identical strategy regardless of what worked/failed previously
5. **Threshold Brittleness**: Fixed margin requirements (8%, 12%) don't adapt to volatility
6. **Missing Context**: Ignores time-of-day patterns, demand forecasting, and seasonal effects

**Why Current Score Stagnates**: At iteration 4, the system found a local optimum (-4.48) but oscillates around it because rigid rules can't adapt to the 10.1% price volatility.

---

## Proposed Solution: Adaptive Window-Based Control with Real-Time Regime Switching

### Core Philosophy
Instead of margin-based thresholds, use **multi-horizon price windows** combined with **volatility-adaptive decision thresholds** and **outcome-based learning**.

        older = list(self.price_history)[-60:-20] if len(self.price_history) >= 60 else recent

        ]

        trend_strength = abs(recent_slope)

        long_mean = sum(self.price_history) / len(self.price_history)
        deviations = [(p - long_mean) / (long_mean + 1e-6) for p in recent]
        mean_reversion_strength = abs(sum(deviations) / len(deviations))
        
        # Classify regime
        if volatility > 0.08 and trend_strength > 0.05:
            regime_type = "high_vol_trending"
        elif volatility < 0.04 and mean_reversion_strength > 0.08:
            regime_type = "low_vol_mean_reverting"
        else:
            regime_type = "volatile_choppy"
        
        return PriceRegime(
            volatility=volatility,
            trend_strength=trend_strength,
            mean_reversion_strength=mean_reversion_strength,
            regime_type=regime_type
        )
    
    def _multi_horizon_prediction(self, price_history: deque) -> dict:
        """Predict prices at multiple horizons simultaneously"""
        if len(price_history) < 5:
            current = price_history[-1] if price_history else 0
            return {h: [current] * 3 for h in self.horizons}
        
        predictions = {}
        recent_prices = list(price_history)[-30:]
        long_mean = sum(price_history) / len(price_history)
        
        for horizon in self.horizons:
            # Simple but effective: exponential smoothing with trend
            alpha = 2.0 / (horizon + 1)
            forecast = []
            current_pred = recent_prices[-1]
            trend = (recent_prices[-1] - recent_prices[-min(5, len(recent_prices))]) / max(1, len(recent_prices)-1)

                # Mean reversion component strengthens over longer horizons
                reversion_factor = min(0.3 * (step + 1) / 3, 0.3)
                current_pred = (alpha * current_pred + 
                               (1 - alpha) * long_mean * (1 + reversion_factor * 
                               (long_mean - current_pred) / (long_mean + 1e-6)))
                current_pred = max(0.1, current_pred)
                forecast.append(current_pred)
                
                # Decay trend over time
                trend *= (1 - 0.1 * (step + 1))
            
            predictions[horizon] = forecast
        
        return predictions

                expected_margin = ((current_price * time_decay - expected_future) /

                               (current_price + 1e-6))

    def _adaptive_threshold(self, regime: PriceRegime, soc: float) -> float:
        """Dynamically adjust margin threshold based on regime and SOC"""
        
        base = self.base_margin_threshold
        
        # Regime adjustment
        if regime.regime_type == "high_vol_trending":
            # In trending markets, require HIGHER margins (more certainty needed)
            base *= 1.3
        elif regime.regime_type == "low_vol_mean_reverting":
            # In mean-reverting markets, lower threshold (higher probability)
            base *= 0.7
        else:
            # Choppy markets: conservative
            base *= 1.1
        
        # SOC adjustment
        if soc < 0.3:
            # Low battery: aggressive charging (lower threshold)
            base *= 0.75
        elif soc > 0.8:
            # High battery: aggressive discharging (lower threshold)
            base *= 0.75
        
        # Volatility adjustment - higher volatility = higher threshold needed
        vol_adjustment = 1.0 + (regime.volatility / 0.10)  # Normalized to 10% baseline
        base *= vol_adjustment
        
        return max(0.02, min(0.20, base))  # Bounds: 2-20%

                return True

        self.base_margin_threshold = max(0.04, min(0.12, self.base_margin_threshold))
